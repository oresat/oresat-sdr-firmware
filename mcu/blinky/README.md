Small blinky project to test your STM32U5!

If your using a different chip:

* Change the chip in `Cargo.toml` and `.cargo/config.toml` to your chip
* Change the pin in `src/main.rs` to one that matches your board


# Running Blinky

If you have your config setup to target your chip, you can run blinky with

```
cargo run
```
